# Site Institucional - LPTI Tech (v1.3)

Site institucional oficial da **LPTI Tech** — *Tecnologia e Gestão para MEIs e Pequenas Empresas*.

## 🚀 Posicionamento Estratégico (v1.3)

A LPTI Tech atua como parceira tecnológica e administrativa para microempreendedores, autônomos e pequenos negócios no Brasil:
- **Gestão para MEIs:** Emissão de DAS, Declaração Anual (DASN-SIMEI), apoio administrativo e controle de obrigações.
- **Soluções Digitais & Nuvem:** Microsoft 365, e-mail corporativo, suporte técnico especializado.
- **Desenvolvimento & Automação:** Desenvolvimento de sistemas web/mobile sob medida e automação de rotinas operacionais.
- **Gestor MEI:** Sistema de gestão financeira, emissão de propostas, fluxo de caixa e controle operacional desenvolvido pela LPTI Tech.

## 📁 Estrutura de Arquivos

- `index.html` - Página principal do site institucional (v1.3)
- `styles.css` - Estilos corporativos modernos, responsivos e acessíveis
- `script.js` - Interatividade, menu mobile drawer, navegação suave e integração de formulário
- `politica-de-privacidade.html` - Página legal de Política de Privacidade (em conformidade com LGPD)
- `termos-de-uso.html` - Página legal de Termos de Uso
- `favicon.ico` - Favicon multi-resolução
- `assets/` - Logotipos oficiais, ícones de sistema e imagens da plataforma Gestor MEI

## 🛠️ Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 Moderno (Custom Properties, Flexbox, Grid, Animações Suaves)
- JavaScript Vanilla (Zero dependências externas pesadas)
- Integração FormSubmit (Entrega direta via Cloudflare Email Routing)
